# Structural Scan v1 — $149 Entry Engagement

**Status:** Commercial validation draft  
**Price:** $149  
**Purpose:** Low-friction structural review before a full Agent Authority Audit

## 1. Scope unit

One narrowly bounded agent/workflow surface, limited to:

- 1 repository;
- 1 environment;
- up to 3 material principals;
- up to 3 integrations/tool surfaces;
- up to 8 material authority paths;
- up to 12 substantive evidence-source items.

If the requested surface exceeds these caps, the client is offered a re-scope or the full Agent Authority Audit. The scan does not silently expand.

## 2. Turnaround

Target: **3 business days** after complete intake and access readiness.

Blocking access, materially incomplete scope, or client-requested holds pause the clock.

## 3. Required inputs

- repository/read-only access for the agreed scope;
- named environment;
- known agent/runtime entry point;
- known integrations/tool surfaces;
- any available configuration/workflow/policy material;
- one technical contact for material ambiguity.

Raw passwords, API keys, private keys, recovery codes, or secret values must not be submitted through ordinary intake or audit artifacts.

## 4. Evidence standard

The scan uses the same evidence states as the full audit:

`VERIFIED / PARTIALLY_VERIFIED / CLAIMED / UNKNOWN`

However, the scan is intentionally shallower. VERIFIED applies only to the exact bounded claim whose evidence threshold is met; the scan does not claim exhaustive path discovery or organization-wide enforcement assurance.

## 5. Outputs

The client receives:

1. **Structural Map** — compact actor → identity → tool/integration → resource → action/gate view for the bounded surface.
2. **Top Findings** — up to 5 material authority/control observations.
3. **Evidence State Notes** — what is directly supported, partial, claimed, or unresolved.
4. **Next-Step Recommendation** — no action, targeted internal remediation, or recommendation for a full Agent Authority Audit.

The Structural Scan does **not** include the full Authority Map, full edge/claim ledger, aggregate-authority analysis across broad integrations, comprehensive remediation plan, or control-plane fit assessment included in the Agent Authority Audit.

## 6. Validation posture

Passive evidence analysis only. No live bypass attempts, grant mutation, production effects, penetration testing, or destructive testing.

## 7. Explicit exclusions

The scan is not:

- a penetration test;
- a compliance/legal certification;
- a complete security review;
- a guarantee that no alternate authority path exists;
- organization-wide discovery;
- implementation/remediation work;
- authorization to change client systems.

## 8. Relationship to the Agent Authority Audit

The Structural Scan is a distinct product, not a discounted version of the full audit.

| Structural Scan | Agent Authority Audit |
|---|---|
| $149 | separately priced fixed-scope engagement |
| 1 repo / 1 environment | up to 3 repos / 2 environments by standard v1 scope |
| 3 principals / 3 integrations | 10 principals / 8 integrations |
| 8 authority paths | 25 authority paths |
| 12 evidence items | 40 evidence items |
| compact structural map | full Authority Map + edge/claim ledger |
| up to 5 findings | full findings register |
| limited next-step recommendation | prioritized remediation + control-plane fit |
| no broad aggregate-authority analysis | aggregate-authority analysis included |
| 3 business day target | 48-hour target after scope freeze/access readiness |

A Structural Scan may identify that the bounded surface merits a full audit, but purchase of the scan does not commit the client to any follow-on engagement.

## 9. Access closure

All scan access must be removed or expired at delivery unless a separately authorized follow-on engagement explicitly governs continued access.
